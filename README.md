# 💳 Credit Card Project – Machine Learning

## 📌 Project Overview

This project focuses on analyzing **credit card data** using Python and applying **Machine Learning techniques** to build and evaluate predictive models.

The project covers the complete workflow from **data loading and exploration to data preprocessing, machine learning model building, and model evaluation**.

The main objective is to understand the patterns in credit card data and use machine learning algorithms to make predictions based on the available features.

## 📂 Project Workflow

The project follows these major steps:

### 1. Data Collection

The credit card dataset is loaded into Python for further analysis.

### 2. Data Exploration

The dataset is examined to understand:

* Number of rows and columns
* Data types
* Statistical information
* Missing values
* Duplicate records
* Feature distributions

### 3. Data Cleaning

The dataset is cleaned by:

* Handling missing values
* Removing duplicate records
* Identifying inconsistent data
* Checking for outliers where required

### 4. Exploratory Data Analysis (EDA)

Different visualization techniques are used to understand the dataset.

Some of the techniques include:

* Histograms
* Box plots
* Count plots
* Correlation analysis
* Heatmaps
* Distribution plots

### 5. Data Preprocessing

The data is prepared for machine learning by performing necessary preprocessing steps such as:

* Feature selection
* Encoding categorical variables
* Feature scaling
* Splitting the dataset into training and testing data

### 6. Machine Learning Model Building

Machine learning algorithms are applied to the preprocessed dataset.

The models are trained using the training dataset and tested using unseen test data.

### 7. Model Evaluation

The trained models are evaluated using appropriate performance metrics such as:

* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix

The evaluation results are used to understand how well the models perform.

## 📈 Model Evaluation

The performance of the developed machine learning models is evaluated using classification metrics.

### Confusion Matrix

A confusion matrix is used to compare the actual and predicted values and identify:

* True Positives
* True Negatives
* False Positives
* False Negatives

### Accuracy

Measures the overall percentage of correct predictions.

### Precision

Measures how many of the predicted positive observations are actually positive.

### Recall

Measures how many of the actual positive observations are correctly identified.

### F1-Score

Provides a balance between precision and recall.
